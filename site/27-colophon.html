附录 C 构建、验证与修订说明

一套章节，两种阅读载体

本书由 chapters/ 中的 Markdown 原稿构建。scripts/build.py 生成合订原稿、EPUB 3 和逐章静态网页。网页正文直接由 Pandoc 输出，无需客户端 JavaScript 才能阅读；脚本只增强搜索、主题、字号与阅读位置。

在已安装 Python 3.9 或更高版本及 Pandoc 的环境中运行：

python3 scripts/build.py
python3 scripts/check.py
python3 -m unittest discover -s labs -v
node --check web/reader.js

不需要四个上游仓库也能重建书籍。research/sources.json 已保存研究快照身份；只有重新采集证据时才需运行 scripts/snapshot.py --source-root /your/source/root。不要为了重建 EPUB 无意中把研究对象更新成另一个版本。

验证分别证明什么

出版结构检查验证 EPUB 的文件封装、包清单、阅读顺序、XML 和内部引用，并检查网页链接、资源与证据编号。EPUBCheck 若完成运行，结果另存验证报告。结构有效不保证每一台阅读器的字体和排版完全相同，也不代替编辑校对。

实验测试验证本仓库教学程序的执行和恢复，不代表已经运行四个上游产品测试。源码索引校验验证文件身份与定位，Claude Code 的 map 对照验证本地提取一致性，不代表材料来源认证。在线发布状态则由 GitHub Pages 部署和访问检查独立确认。

本版的内容边界

本书没有公布真实模型性能排名，没有把项目中的配置默认值写成永久承诺，没有将可见特性分支当作所有用户都可用的功能。代码引用链接固定到本地 Git 提交；官方资料只用来补充术语，访问日期与源码快照日期分别说明。

原始发布包、压缩包、凭据、上游工作区修改和既有书稿没有并入本书仓库。许可证说明区分原创分析、实验代码及被分析项目，完整出处见 NOTICE.md。

修订方法

如果升级上游，先重新采集快照，再比较核心循环、工具类型、请求准备、取消和持久格式。更新受影响章节和验证，而非只替换提交号。若新版本不再支持某条路径，应明确记录失效范围。

本版为 1.0.0，研究日期 2026-10-30。建议反馈包含章节名、证据编号、所用提交和具体不一致现象，这样修订可以追踪到实际机制。
